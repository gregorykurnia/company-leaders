# company-leaders

Next.js app for tracking top companies' leadership (CEO, President Commissioner) by country, split into Indonesia / USA tabs. Data in Firestore, photos uploaded to Cloudinary, deployed on Vercel.

## Workflow

After making any code change, commit and push it to `main` immediately (no need to ask first), then tell the user in plain language what changed. Never commit `.env.local` or any file containing credentials.
